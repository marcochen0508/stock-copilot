# 📈 台股智能決策戰情室 (Stock Copilot)

專為個人與家族量身打造的跨市場量化投資決策系統，整合**「美股先行指標」、「Google 雲端試算表多帳戶自動同步」、「持股成本量化買賣診斷」**與**「即時巨幕 K 線走勢圖」**。

---

## 🌟 核心特色

1. **美股宏觀先行指標與開盤前瞻**：
   - 即時追蹤：費城半導體 (SOX)、台積電 ADR (TSM)、那斯達克、標普 500、道瓊、輝達 (NVDA)、恐慌指數 (VIX)、美元/台幣匯率。
   - 自動運算今日台股開盤動能評分（如：強勢偏多開高 +68分）與大白話晨報點評。
2. **無縫同步 Google 雲端試算表**：
   - 支援多人/多帳戶分頁籤管理（如：`台北-阿良`、`三重-甘露涓`、`景維`、`阿輝`、`全部合併總覽`）。
   - 在手機 Google Sheets 修改持股，戰情室點擊「同步試算表」立刻更新。
3. **個人化進出場量化決策**：
   - 針對每位親友的**真實買進成本**，計算未實現損益、報酬率、關鍵防守停損價、移動停利點與多空指引。
4. **即時巨幕線圖視窗**：
   - 點擊持股或自選股，立即彈出超大 K 線圖視窗，支援證交所 0 延遲行情、日K/週K 切換與均線指標。
5. **未持股觀察雷達 (Watchlist)**：
   - 評估最佳進場時機（量縮拉回守月線、帶量突破），先精算「風險報酬損益比（如 1:3.8）」再考慮進場。
