# 隱私與敏感資訊防護鐵律 (Strict Privacy & Sensitive Data Protection Rules)

## 核心最高原則
**嚴禁在任何程式碼、預設值、常數、範例設定或伺服器快取中，寫入使用者的任何私密或真實資料！**

### 1. 絕對禁止寫入程式碼的資訊：
- **個人 / 家庭 Google 試算表 ID 或完整網址**（絕對不可設為預設值或 fallback）。
- **真實姓名、親友姓名、帳戶名稱**（如家人、朋友名稱、帳號代號）。
- **真實持股明細、持有股數、買進成本、金額、損益紀錄**。
- **個人 Token、API Key、密碼、帳號憑證**。

### 2. 資料存取與展示架構原則：
- **公共服務架構**：所有公開部署（如 Render、Vercel 等）的網站伺服器必須對所有人保持純淨、無使用者狀態（Stateless）。
- **端點隔離（Client-side Only）**：使用者的個人試算表網址、手動持股資料、筆記備忘，**一律只能儲存於使用者個人的本機瀏覽器（localStorage）**，換電腦或換瀏覽器必須由使用者自行重新輸入，絕不可在後端全域共享。
- **後端預設狀態**：後端若未收到使用者前端帶入的參數，一律回傳空白或通用示範模板，絕不可 fallback 到任何特定使用者的資料。
- **Git 提交通知**：進行任何 Git commit 與 push 前，必須主動檢查是否夾帶任何個人資訊或真實資料。
